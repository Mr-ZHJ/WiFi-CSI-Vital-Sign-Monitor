# 项目概述：基于 WiFi CSI 的非接触生命体征监测

> 本文档面向仓库背景，介绍项目的研究背景、研究目标与意义，是 `README` 的扩展阅读材料。

---

## 1. 研究背景

### 1.1 传统人体感知技术的局限

人体行为与生命体征监测在健康监护、智慧照护、智能家居等领域具有广泛需求。传统技术路线存在明显局限：

| 技术路线 | 主要局限 |
| --- | --- |
| 计算机视觉 | 依赖视距（LOS），易受光照影响，且严重侵犯用户隐私 |
| 可穿戴传感器 | 需要佩戴智能手表、手环等设备，对老年人或行动不便者不友好，设备成本较高、普及度有限 |
| 雷达 | 空间分辨率较低，难以捕捉细粒度人体动作，成本偏高 |

因此，探索一种**非接触、低成本、不侵犯隐私**的人体感知方式具有重要意义。

### 1.2 WiFi 感知的兴起

WiFi 已实现室内场景的广泛覆盖，天然具备普适性。**CSI（Channel State Information，信道状态信息）** 可提供 WiFi 信号在每一个 **OFDM（Orthogonal Frequency Division Multiplexing，正交频分复用）** 子载波上的幅度与相位响应，包含了丰富的多径传播信息。当人体呼吸、心跳或肢体动作引起体表微动时，会稳定调制相关子载波的 CSI 特征，从而支持：

- **非接触生命体征监测**：呼吸频率估计与分类、心跳频率估计与分类
- **人体活动识别**：睡眠姿态、翻身/周转活动及常见动作的细粒度识别

相比 **RSS（Received Signal Strength，接收信号强度）** 仅能提供单个粗粒度强度值，CSI 能提供更细粒度的子载波级信息，是支撑呼吸、心跳这类微动感知的关键。

### 1.3 研究方向定位

本项目定位于 WiFi 感知在**非接触健康监护**中的应用，重点关注**相对静止姿态**（尤其睡眠场景）下的生命体征监测，并兼顾人体活动识别。研究期间调研与接触的采集平台包括：Intel 5300 NIC、Atheros CSI Tool、Nexmon CSI Tool、ESP32 CSI Tool、SDR（Software Defined Radio，软件无线电）等；本仓库以 **Intel 5300 NIC + Linux 802.11n CSI Tool** 为主线实践。

## 2. 项目目标

### 2.1 总体目标

构建一套基于 WiFi CSI 的**非接触睡眠生命体征监测系统**，打通“硬件搭建 → 数据采集 → 数据预处理 → 算法建模 → 生命体征提取”的完整链路，并将过程中形成的笔记、脚本与经验沉淀为可复现的开源研究资料。

### 2.2 具体任务

| 编号 | 任务 | 说明 |
| --- | --- | --- |
| T1 | 呼吸监测 | 呼吸频率估计（回归）与呼吸状态分类 |
| T2 | 心跳监测 | 心跳频率估计与心跳状态分类 |
| T3 | 睡眠姿态识别 | 仰卧（supine）、右侧卧（right-side lying）、俯卧（prone）、左侧卧（left-side lying）等 |
| T4 | 睡眠周转活动识别 | 睡眠中翻身等周转动作识别（如 S→R、S→L、L→S、L→P、R→S、R→P、P→R、P→L） |
| T5 | 人体活动识别 | 卧床、摔倒、步行、拾取、跑步、坐下、站立等 |
| T6 | 长时间睡眠监测 | 睡眠活动与非睡眠活动时段区分，并持续进行呼吸频率监测 |

### 2.3 睡眠监测实验设计（供复现参考）

- **采集平台**：Intel 5300 NIC，Monitor 模式，2 台装有 Intel 5300 网卡的台式机完成收发
- **应用场景**：居家环境（床上）
- **天线布置**：分散布置——3 根接收天线放置在**肩膀、腰部和脚边**；或 2 根接收天线**对角布置**
- **天线选择**：全向天线
- **数据采集**：
  - 短时采集：4 种睡眠姿态下的呼吸频率数据；8 种周转活动的训练数据
  - 长时采集：1 个完整长时间序列，用于长时间睡眠监测
- **实验对照**：
  - 呼吸频率控制：节拍器
  - 呼吸频率检测：指压式血氧仪、呼吸带传感器
- **实验器材**：WiFi 信号延迟线（3 条 × 3 m）、三角支架 + 泡沫/塑料用于固定天线、指压式血氧仪 / 呼吸带传感器、床/床垫、可选 2.5G/5G 小吸盘天线（3 个）

## 3. 研究意义

1. **非侵入健康监测**：无需佩戴设备即可连续监测呼吸与心跳，尤其适合老人、婴幼儿、睡眠障碍人群等。
2. **隐私保护**：不采集图像/视频，天然规避隐私泄露问题。
3. **低成本普适部署**：利用现有商用 WiFi 基础设施，无需专用感知设备，具有普适部署潜力。
4. **学科交叉积累**：为 WiFi 感知方向（CSI 处理、信号去噪、深度学习分类）的入门研究者提供一套可对照的流程与代码参考。

## 4. 研究路线总览

```
硬件搭建（Intel 5300 + CSI Tool）
   │
   ▼
数据采集（Monitor 模式、20 Hz、.dat 原始数据）
   │
   ▼
数据预处理（解析 → 幅值/相位 → 子载波筛选 → 融合 → 去噪/异常值剔除 → 活动分割）
   │
   ▼
算法建模（SM-TCNNET / LSTM，K 折交叉验证）
   │
   ▼
生命体征提取（呼吸 / 心跳频率估计）与活动识别
```
